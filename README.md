# آوا — دستیار صوتی فارسی، کاملاً لوکال

یک دستیار صوتی که همه‌ی اجزایش روی دستگاه خودت اجرا می‌شود و به هیچ کلید API نیازی ندارد:

| بخش | ابزار | توضیح |
|---|---|---|
| تشخیص گفتار | `faster-whisper` | آفلاین، فارسی |
| کلمه‌ی بیدارباش | ویسپرِ سبک | با گفتن «آوا» فعال می‌شود |
| مغز متفکر | **Ollama** (`qwen2.5:3b` پیش‌فرض، `qwen2.5:7b` برای کیفیت بالاتر) | مدل زبانی لوکال |
| تبدیل متن به گفتار | **Piper** (`fa_IR-amir-medium`) | آفلاین |
| جست‌وجوی وب | `ddgs` (داک‌داک‌گو) | بدون کلید، فقط برای داده‌ی زنده |
| حافظه | فایل JSON | اصولی که به آوا یاد می‌دهی ماندگار می‌ماند |

## نصب

پیش‌نیاز: پایتون ۳.۱۰ به بالا و [Ollama](https://ollama.com).

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m scripts.download_models
```

`download_models` صدای فارسی Piper را دانلود می‌کند و اگر Ollama نصب باشد مدل زبانی را هم می‌کشد.
اگر خودکار انجام نشد، دستی اجرا کن:

```bash
ollama pull qwen2.5:7b
```

مطمئن شو سرویس Ollama در حال اجراست (`ollama serve` یا برنامه‌ی دسکتاپ باز باشد).

## اجرا

```bash
python main.py --gui           # رابط تصویری (پیشنهادی — فارسی درست نمایش داده می‌شود)
python main.py                 # حالت ترمینال («کلید و صحبت»: Enter بزن و بپرس)
python main.py --text          # تست بدون میکروفون (فقط مغز + جست‌وجو + حافظه)
python main.py --list-devices  # دیدن شماره‌ی دستگاه‌های صوتی
python main.py --forget        # پاک کردن حافظه
```

در رابط تصویری: دکمه‌ی «صحبت کنید» (یا کلید Space) را بزن، سؤالت را بپرس، ساکت شو.

نحوه‌ی تعامل در `config.yaml` با `interaction` تنظیم می‌شود:
`push_to_talk` (پیش‌فرض، مطمئن) یا `wake` (با گفتن «آوا»، فقط با میکروفون خوب).

در حالت صوتی: بگو «آوا»، صدای بوق را بشنو، سؤالت را بپرس؛ آوا وقتی سکوت کردی جواب می‌دهد.

## تنظیمات

همه‌چیز در [`config.yaml`](config.yaml) قابل تغییر است: نام مدل‌ها، دستگاه صوتی،
حساسیت تشخیص سکوت، مدت سکوتِ پایانِ جمله، و روشن/خاموش بودن جست‌وجوی وب.

### نکته‌های کارایی

تنظیمات پیش‌فرض برای همین لپ‌تاپ (Core i7-8550U، ۱۶ گیگ رم، بدون GPU کارآمد) میزان شده:
`qwen2.5:3b` + ویسپر `base` + کلمه‌ی بیدارباش با ویسپر `tiny`. در هر نوبت فقط یک بار
مدل زبانی صدا زده می‌شود (تصمیم جست‌وجو و تشخیص «آموزش» با قاعده‌های سبک انجام می‌شود).

- کیفیت پاسخ مهم‌تر از سرعت است؟ در `config.yaml` مقدار `llm.model` را `qwen2.5:7b` کن
  (کندتر، ولی روان‌تر و کم‌خطاتر).
- بار اول که مدل در حافظه می‌آید چند ده ثانیه طول می‌کشد؛ `llm.keep_alive` باعث می‌شود
  در نوبت‌های بعد سریع باشد.
- کارت گرافیک انویدیا قوی داری؟ `stt.device: cuda` و `stt.compute_type: float16` و
  `stt.model: small` یا `medium`.

## ساختار

```
main.py                  نقطه‌ی ورود و آرگومان‌ها
config.yaml              پیکربندی
ava/
  assistant.py           حلقه‌ی اصلی: بیدارباش → گوش دادن → پاسخ
  audio_io.py            میکروفون پیوسته + پخش صدا
  recorder.py            تشخیص پایان جمله با VAD
  stt.py                 رونویسی با faster-whisper
  tts.py                 گفتار با Piper
  llm.py                 اتصال به Ollama + منطق جست‌وجو و حافظه
  memory.py              حافظه‌ی ماندگار JSON
  websearch.py           جست‌وجوی داک‌داک‌گو
  utils.py               یکدست‌سازی متن فارسی
scripts/download_models.py  دانلود مدل‌ها
```

## محدودیت‌های نسخه‌ی فعلی و گام‌های بعدی

- بدون «قطع‌کردن وسط حرف» (barge-in)؛ تا وقتی آوا حرف می‌زند گوش نمی‌دهد.
- پاسخ به‌صورت یکجا ساخته و بعد خوانده می‌شود؛ می‌توان جمله‌به‌جمله استریم کرد.
- تشخیص بیدارباش مبتنی بر ویسپر است؛ برای دقت بیشتر می‌توان از `openWakeWord` استفاده کرد.
